# 角色卡管理器 (Character Manager)

一款酒馆角色卡管理插件，提供角色卡的查看、筛选、编辑、标签管理、翻译、画廊管理等一站式解决方案。

---

## 功能特性

### :clipboard: 角色卡管理

- 卡片展示：卡片网格展示，支持缩放调整，图片懒加载优化性能
- 快速筛选：按标签筛选、收藏筛选、重复检测
- 多种排序：按名称、时间、Token数量、画廊图片数量排序，插件独有字段按导入时间排序
- 批量操作：长按进入批量操作模式
- 随机角色卡：短按随机，长按配置
- 收藏与重复检测：一键收藏，智能检测重复角色卡
- 特殊边框样式：置顶当前聊天角色卡，已收藏卡片粉嫩边框、重复卡边框
- 封面显示模式：正常/SFW(模糊)/无图，可选作用于列表页或详情页

### :label: 标签系统

- 使用自定义字段保存标签，如需同步到角色卡原始tag字段需要在设置界面打开`同步到原生标签`（默认关闭）
- 支持从角色卡元数据自动导入标签，批量添加标签
- 标签同步写入角色卡文件，便于多端同步备份
- 一键清除空标签、一键清除角色所有标签

### :globe_with_meridians: 内置翻译功能

内置角色卡翻译引擎，基础框架移植自我的这个项目：https://discord.com/channels/1134557553011998840/1457629333412905154
**提示：翻译的角色卡仅供自己使用，请勿二传**

- 翻译服务：自定义OpenAPI兼容端点、酒馆原生API（实验性）
- 智能翻译：自动识别翻译内容，内置简单破限
- 术语表管理：自定义术语表，AI辅助术语筛选翻译
- MVU框架保护：自动检测保护变量及脚本内容（实验性，如有问题请反馈）
- 进度保存：翻译进度可导出
- 防截断模式：单词条发送请求，避免批量翻译截断
- 流式传输优化：截断时可识别已接收区块
- **导出选项**：
  - 导出翻译后的 PNG 文件
  - 导出 JSON 数据
  - 直接覆盖原角色卡
  - 作为新角色卡导入

### 🤖 AI功能
- AI 智能概览（自动生成角色简介摘要）
- AI 批量生成标签
- **批量AI概览弹窗增强**：
  - 支持逐个处理和批量处理两种模式
  - 可自定义生成内容：概览+标签、仅概览、仅标签
  - **覆盖选项**：可独立控制是否覆盖已有标签和概览
  - 智能跳过机制：根据覆盖选项自动跳过已有内容的角色

### :frame_photo: 画廊管理

- 查看角色画廊图片，支持上传、删除、批量操作
- 从画廊选图裁剪设为封面
- 灯箱大图预览，支持键盘导航
提示：智绘姬插件生成的图是存在智绘姬文件夹里的，角色卡管理查不到，只能去智绘姬里清理

### :link: URL 导入

- 输入图片直链自动下载导入（如 Discord 链接，在discord里点开图片-点更多-复制链接）
- 支持预填元数据（来源链接、备注、标签）
- 自动将元数据写入角色卡文件

### :pencil: 详情页与编辑

- 视图模式：标签页视图（现代布局）、经典视图（传统滚动）
- 详情模块：Source URL字段、自定义用户备注字段、格式化渲染描述（支持HTML和Markdown格式）、宏替换高亮（显示`{{user}}`、`{{char}}`、引号为自定义颜色）
- 开场白模块：查看默认和备选开场白，备选开场白可展开全屏查看
- 聊天记录模块：查看历史、显示计数、删除聊天文件
- 扩展模块：角色世界书、绑定正则脚本、酒馆助手脚本
- 编辑功能：编辑角色卡基础信息、角色世界书
- 角色卡更新：直接在详情页导入新卡覆盖
- 收藏同步：收藏状态与酒馆原生系统互通

### :art: 界面自定义

- 深色/浅色主题切换
- 卡片缩放调整
- 徽章显示（画廊数量、Token数量）
- 列表显示选项（作者名、悬浮按钮、卡片注释）
- 宏替换颜色主题（8种预设 + 自定义）

---

## 使用指南

插件入口在输入框旁边的**魔法棒**，可在设置界面启用悬浮球入口或快捷键打开
